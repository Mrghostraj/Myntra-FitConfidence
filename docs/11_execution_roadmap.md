# Execution Roadmap

A proposed timeline for a student portfolio prototype; adjust based on available time.

## Week 1 — Product & UX foundation
- Finalize discovery docs and requirements.
- Define sample data schema and recommendation rules.
- Design Figma wireframes and flow.

## Week 2 — Core MVP
- Build body profile and preference UI.
- Implement unit conversion/validation.
- Implement rule-based sizing over sample data.
- Add explanation and fallback.

## Week 3 — Prototype integration and usability
- Connect frontend/API/data.
- Add length cues and feedback capture.
- Run small usability sessions and document findings.

## Week 4 — Advanced AI exploration and case study
- Experiment with visual simulation (only if time/data allows).
- Evaluate visual product consistency and limitations.
- Update portfolio case study with prototype screenshots and test results.

## Definition of Done (core MVP)
- Flow is usable end-to-end on sample data.
- Size recommendation uses documented rules and available dimensions.
- Explanation is consistent with inputs.
- Missing data leads to fallback.
- User can edit and rerun.
- Test cases documented.
- No production affiliation or accuracy claims.
