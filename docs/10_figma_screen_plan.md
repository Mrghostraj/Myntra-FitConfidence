## Screen inventory
| Screen | Content | Release |
|---|---|---|
| 1. Product Detail Page | Product info, size selector, “Find My Fit” CTA | MVP |
| 2. Body Profile | Height, chest, optional weight, measurement units | MVP |
| 3. Fit Preference | Slim / Regular / Relaxed choices | MVP |
| 4. Recommendation Result | Size, rationale, fallback/alternative | MVP |
| 5. Estimated Fit/Length | Approximate cues based on product dimensions | P1 |
| 6. Visual Fit Preview | AI simulation with clear labeling | Advanced |
| 7. Fit Feedback | Too tight / as expected / too loose; length feedback | P1 |
| 8. Privacy/Personalization controls | Consent, purchase history toggle, data edit | MVP design requirement |

## UX requirements
- Mobile-first, short flow.
- Use explicit units and measurement helper text.
- Explain recommendation evidence.
- Clearly distinguish estimates from facts.
- Never imply an AI-generated visual is a true photo or guaranteed fit.
- Provide fallback and error states.
